## About this entry

The excuse is built as a defence, never an apology and never
a confession: the glass moved first, the cat was only running
a stability test, and the results are conclusive. That is cat
logic at its most convincing — the animal reframes a disaster
as an experiment and reports findings instead of saying sorry.
The line stays in the cat's own voice the whole way through,
and it names the real physics of the scene, a table that is
too high and a floor that is too hard, which is exactly the
kind of specific, testable claim a judge finds harder to
dismiss than a vague "it was an accident". The glass is the
culprit, the cat is the researcher, and the floor is the
problem, which is the most convincing case a cat can make for
itself in five seconds. The program holds the line, checks it
against the two hundred character cap and the no-apology rule,
and writes it to /output/entry.txt exactly as the bounty
requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
